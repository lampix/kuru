# 0001 — Use FSRS-6 instead of FSRS-5

- **Status:** Accepted
- **Date:** 2026-10-13

## Context
The design document specifies FSRS v5 with weights `w0…w18`. The current stable releases of the official
libraries (`fsrs` 6.x on PyPI, `ts-fsrs` 5.x on npm) implement FSRS-6 with 21 weights (`w0…w20`), and Anki
itself has moved to FSRS-6. Pinning outdated library versions would freeze us on unmaintained code.

## Decision
Kuru uses FSRS-6 via the latest `fsrs` and `ts-fsrs`. When an imported Anki preset carries 19 FSRS-5
weights, they are extended with the FSRS-6 default values for `w19` and `w20`, which reproduces FSRS-5
behaviour closely. 17-weight (FSRS-4.5) parameter sets are discarded in favour of the defaults.

## Consequences
- The weights editor shows 21 values.
- The optimizer produces FSRS-6 parameters.
