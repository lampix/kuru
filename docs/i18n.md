# Internationalisation

Kuru ships English (`en`) and German (`de`) using [next-intl](https://next-intl.dev/).

## Language selection

1. **Manual override** — Settings → Language stores the choice in `localStorage` and the
   `kuru-locale` cookie.
2. **System preference** — otherwise the device languages (`navigator.languages`) decide.
3. **Fallback** — anything other than German or English uses English.

The locale is part of the URL (`/en/…`, `/de/…`); every page is prerendered for both locales and
read with `next/root-params`. `/` is a static page that applies the cascade above on the client
(`app/(root)/page.tsx`) — it works offline and needs no server-side proxy.

## Adding or changing strings

* Strings live in `frontend/messages/{en,de}.json`, grouped by screen.
* Every key must exist in all locales — `src/i18n/detect.test.ts` enforces this.
* Use ICU message syntax for plurals: `"{count, plural, one {# card} other {# cards}}"`.

## Adding a language

1. Add the code to `locales` in `src/i18n/routing.ts`.
2. Create `messages/<code>.json` with all keys.
3. Add the option to `components/settings/language-setting.tsx` and the `settings.language*` keys.
